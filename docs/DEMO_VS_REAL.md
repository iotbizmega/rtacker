# دمو در برابر سامانهٔ واقعی

هر ردیف: چیزی که الان در دمو شبیه‌سازی می‌شود، کجای کد است و در سامانهٔ واقعی چه چیزی جایش می‌آید.

| قابلیت در دمو | کجا در کد | در سامانهٔ واقعی |
|---|---|---|
| ۳۰ خودرو، ناوگان، رانندگان، دستگاه‌ها | تولید در `live.js` (`V`, `DRV`, `ID`, `LS`) | جدول‌های Fleet/Vehicle/Driver/Device در دیتابیس؛ CRUD با API |
| موقعیت و سرعت زنده | `step()` + `vGP`/`prof` + `at(RT[i], p*PKF(i))` | دریافت از دستگاه‌ها (TCP/MQTT) → صف → ذخیره + WebSocket به مرورگر |
| ورود/ورود به سامانه (login) | `enter()`/`logout()` بدون رمز | احراز هویت (JWT/OIDC)، نقش‌ها، دسترسی به ناوگان |
| هشدارها (خستگی، تلفن، فاصله…) | `SC` (سناریوی زمان‌بندی‌شده) و `A()` | هشدار از خود دستگاه‌های ADAS/DSM + موتور قوانین سمت سرور |
| گواهینامه منقضی | تاریخ‌ها در `licD()`، آستانه ۳۰ روز | job روزانه روی جدول راننده |
| ویدئوی زنده (دیوار ۴×۲) | کلیپ‌های webm حلقه‌ای | سرور رسانه (RTSP/RTMP/JT1078 → WebRTC/HLS)، احراز مجوز هر استریم |
| ویدئوی تاریخی / کلیپ هشدار | تصاویر/کلیپ ثابت | ذخیره‌سازی شیء (S3/MinIO) + ایندکس زمانی + لینک امضاشده |
| مسیر و سفر | `RT` (مسیرهای نمونه بین شهرها)، صفحهٔ «مسیر» | بازسازی مسیر از TelemetrySample + Map Matching؛ تقسیم سفر با قانون (سوئیچ/توقف) |
| نقشه | Leaflet + کاشی‌های Esri/OSM از CDN | کاشی خودمیزبان یا سرویس داخلی (دسترسی به CDN خارجی از ایران ناپایدار است) |
| خروجی Excel | `dl()` — ساخت xlsx در مرورگر | خروجی سمت سرور برای حجم بالا + ارسال زمان‌بندی‌شده گزارش |
| PDF | چاپ مرورگر | تولید سمت سرور (headless/گزارش‌ساز) |
| لاگ فعالیت | `aud()` در حافظه | AuditLog در دیتابیس |
| حذف/افزودن ردیف، حذف گروهی | آرایهٔ `DB` در حافظه، Undo | endpointهای REST + soft-delete |
| تقویم شمسی، فونت | Part 5g در `live.js` | کتابخانهٔ مناسب (مثل jalaali/dayjs-jalali) |

## چیزهایی که دمو اصلاً ندارد
احراز هویت واقعی، ذخیرهٔ دائمی، چندمستاجری (tenant)، دسترسی به دستگاه/پروتکل، مقیاس‌پذیری، امنیت (رمزنگاری، rate-limit)، پشتیبان‌گیری، مانیتورینگ، نسخه‌بندی API، تست‌های بار.
