# مدل داده — پیش‌نویس اولیه

**منبع:** ستون‌های جدول‌های دمو. این فقط نقطهٔ شروع است؛ نوع فیلدها، کلیدهای خارجی و ایندکس‌ها را تیم بک‌اند باید نهایی کند و با دستگاه‌ها/پروتکل واقعی تطبیق دهد.

## جدول‌های مدیریتی (از صفحات جدولی دمو)

### تنظیمات پیشگیری  (منو: پیشگیری)
ستون‌ها: نام قانون، نوع تشخیص، آستانه، شدت، اقدام، وضعیت

### ناوگان  (منو: عملیات)
ستون‌ها: نام ناوگان، ناوگان والد، تعداد خودرو، مسئول، وضعیت

### خودرو  (منو: عملیات)
ستون‌ها: شناسه، نام خودرو، ناوگان، مدل دستگاه، کانال‌ها، سیم‌کارت، وضعیت

### نقش  (منو: عملیات)
ستون‌ها: نام نقش، توضیحات، تعداد کاربر، سطح دسترسی، وضعیت

### کاربر  (منو: عملیات)
ستون‌ها: نام کاربری، نام و نام‌خانوادگی، نقش، ناوگان، آخرین ورود، وضعیت

### راننده  (منو: عملیات)
ستون‌ها: نام راننده، کد پرسنلی، شماره تماس، گواهینامه تا، خودرو، وضعیت

### پیوند هشدار  (منو: عملیات)
ستون‌ها: نوع هشدار، اقدام پیوندی، کانال، مدت ضبط، وضعیت

### هشدار مجازی  (منو: عملیات)
ستون‌ها: نام هشدار، شرط، خودرو، شدت، وضعیت

### دانلود زمان‌بندی‌شده  (منو: عملیات)
ستون‌ها: عنوان، خودرو، کانال، زمان‌بندی، آخرین اجرا، وضعیت

### نشست مأموریت  (منو: عملیات)
ستون‌ها: عنوان مأموریت، راننده، خودرو، مبدأ، مقصد، شروع، وضعیت

### قوانین آنالوگ  (منو: عملیات)
ستون‌ها: کانال آنالوگ، نام سنسور، واحد، حداقل، حداکثر، وضعیت

### قوانین جریان ویدئو  (منو: عملیات)
ستون‌ها: نام قانون، خودرو، کانال، کیفیت، حداکثر زمان پخش، وضعیت

### قوانین ارسال زمان‌بندی‌شده گزارش  (منو: عملیات)
ستون‌ها: گزارش، دوره ارسال، زمان ارسال، گیرندگان، قالب، وضعیت

### مدیریت فایل‌های صوتی  (منو: عملیات)
ستون‌ها: نام فایل، نوع، مدت، حجم، تاریخ بارگذاری، وضعیت

### نگهداری خودرو  (منو: عملیات)
ستون‌ها: خودرو، نوع سرویس، آخرین سرویس، کیلومتر فعلی، موعد بعدی، وضعیت

### اعزام و سفارش کار  (منو: عملیات)
ستون‌ها: عنوان مأموریت، راننده، خودرو، مبدأ، مقصد، اولویت، وضعیت

### سفارش کار تعمیر  (منو: نگهداری)
ستون‌ها: شماره، خودرو، شرح، اولویت، هزینهٔ تخمینی (تومان)، وضعیت

### گزارش GPS  (منو: گزارش‌ها)
ستون‌ها: خودرو، ناوگان، مسافت (کیلومتر)، مدت حرکت، مدت توقف، بیشترین سرعت

### سوابق GPS  (منو: گزارش‌ها)
ستون‌ها: زمان، طول جغرافیایی، عرض جغرافیایی، سرعت، جهت، سوئیچ

### گزارش هشدار عادی  (منو: گزارش‌ها)
ستون‌ها: خودرو، نوع هشدار، تعداد، آخرین وقوع

### سوابق هشدار  (منو: گزارش‌ها)
ستون‌ها: زمان، خودرو، نوع هشدار، شدت، راننده، وضعیت

## موجودیت‌های زمان‌واقعی/سری زمانی که در دمو شبیه‌سازی می‌شوند (جدول ندارند)
- **TelemetrySample** (device_id, ts, lat, lon, speed, heading, ignition, fuel, engine_temp, odometer, online) — حجم بالا؛ پیشنهاد: پارتیشن زمانی (TimescaleDB یا مشابه) + نگهداری N ماه.
- **Alert** (id, vehicle_id, driver_id, type, severity, ts, status, evidence_clip_id, ack_by, ack_ts) — انواع در دمو: خستگی راننده، استفاده از تلفن، فاصلهٔ ناایمن، ترمز ناگهانی، ورود/خروج از محدوده، قطع ارتباط، پر شدن حافظهٔ DVR، دمای بالای موتور، توقف طولانی با موتور روشن، گواهینامه منقضی/نزدیک موعد.
- **VideoClip** (id, device_id, channel, start_ts, end_ts, storage_url, trigger_alert_id) و **VideoStream** (session، channel، وضعیت).
- **Trip** (id, vehicle_id, driver_id, start/end ts+pos, distance, idle_time, fuel_used, max_speed).
- **GeofenceEvent**، **DriverSafetyScore** (امتیاز روزانه/هفتگی)، **MaintenanceTask/WorkOrder**، **DVIR** (بازرسی روزانه)، **AuditLog** (کنش‌های کاربر).
