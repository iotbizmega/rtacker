# رسانه‌ها و مجوزها — قبل از عمومی‌کردن مخزن بخوانید

**پیشنهاد:** مخزن را **خصوصی (Private)** بسازید تا این موارد بررسی شود.

- `assets/videos/*.webm` و `assets/crops/*.jpg`: برش‌هایی از ویدئوهای آپلودشدهٔ کاربر (جاده/داش‌کم/پایش راننده)؛ منبع و مجوز اصلی این ویدئوها تأیید نشده است. برای نسخهٔ عمومی/تجاری با ویدئو و تصاویر دارای مجوز جایگزین شوند.
- `docs/reference/*.png`: اسکرین‌شات‌های مرجع طراحی (ظاهراً از یک محصول مشابه/بازسازی). مالکیت و اجازهٔ انتشار را مشخص کنید.
- `assets/brand/`: لوگوی سامانه (ارائه‌شده توسط کاربر).
- `assets/fonts/Vazirmatn.woff2`: وزیرمتن، مجوز OFL (آزاد).
- کتابخانه‌ها: Leaflet (BSD-2) و کاشی‌های نقشه (Esri/OSM) شرایط استفادهٔ خودشان را دارند؛ برای تولید، سرویس کاشی مناسب انتخاب شود.
- مجوز کد: هنوز انتخاب نشده (فایل LICENSE نیست).
