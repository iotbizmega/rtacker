# سامانه رهگیری و مدیریت ناوگان

دموی تعاملی (فارسی، راست‌به‌چپ) برای «سامانه رهگیری و مدیریت ناوگان» — با همکاری **مرکز گسترش اینترنت اشیا ایران** ([iotbiz.ir](https://www.iotbiz.ir)).
این مخزن **هنوز بک‌اند ندارد**: همهٔ داده‌ها (ناوگان ۳۰ خودرو، هشدارها، موقعیت‌ها) در مرورگر شبیه‌سازی می‌شوند. هدف مخزن: نقطهٔ شروع تبدیل دمو به سامانهٔ واقعی.

> ⚠️ آنچه در دمو می‌بینید «نمونه» است. ببینید [`docs/DEMO_VS_REAL.md`](docs/DEMO_VS_REAL.md): هر قابلیتِ شبیه‌سازی‌شده و معادل واقعی‌اش.

## اجرای سریع
```bash
python3 build.py                 # خروجی: dist/VSS-Fleet-Platform.html (فایل مستقل ~۴ مگابایت)
open dist/VSS-Fleet-Platform.html   # یا فقط با مرورگر باز کنید
```
فقط نقشه به اینترنت نیاز دارد (Leaflet و کاشی‌ها از CDN). بقیه آفلاین کار می‌کند.

## تست
```bash
pip install -r requirements-dev.txt && python -m playwright install chromium
python tests/smoke.py            # ۴۱ صفحه، موبایل/دسکتاپ، حرکت واقع‌نما، Toast، بدون خطای JS
```
CI (`.github/workflows/ci.yml`) همین را در هر push اجرا می‌کند و دمو را روی GitHub Pages منتشر می‌کند (در Settings → Pages منبع را «GitHub Actions» بگذارید؛ برای مخزن خصوصی به پلن مناسب نیاز است).

## ساختار
| مسیر | توضیح |
|---|---|
| `src/template.html` | قالب اصلی دمو (HTML+CSS+JS، صفحات جدولی `S`، منوها `NAV`) |
| `src/live.js` | موتور شبیه‌سازی زنده و صفحات تکمیلی (هشدار، نقشه، اکسل، تقویم شمسی، …) |
| `build.py` | ویدئو/فونت/لوگو/تصاویر را base64 داخل HTML می‌گذارد |
| `assets/` | لوگو، فونت وزیرمتن، تصاویر و ویدئوهای نمونهٔ دوربین |
| `docs/` | معماری هدف، نقشهٔ راه، مدل داده، لیست صفحات، مرجع طراحی، تاریخچهٔ تصمیم‌ها |
| `tests/smoke.py` | تست دود (Playwright) |
